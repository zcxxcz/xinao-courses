一、七讲是一套完整闭环

讲次 标题 解决的问题 一句话方法论
第①讲 CSP 信奥赛复赛提分：如何检查 提交后不知道错在哪 OI 无反馈，靠「造数据 + 改数据模型」自测
第②讲 稳定 J/S/NOIP 省一的训练方法（打暴力分） 分数从哪来 把「0→100」拆成「0→有分→高分→满分」，用真题暴力分保底
第③讲 NOI 金/银牌训练方法系列：AI 辅助代码优化 会做，但写不快写不稳 用 AI 在不改思路的前提下压缩代码，省出考场时间
第④讲 CSP/NOIP 一等高分需要的刷题量 到底要刷多少题 分层次给量：入门量 / 保奖量 / 冲名次量，暴力练到「够用即止」
第⑤讲 从 26 省选看未来信奥是否会出现新题型 要不要为「没见过的题型」提前准备 交互题先于构造题入场：学会提交格式 + 洛谷 400+ 道题库练手
第⑥讲 信奥学习中 家长对学生的影响（8 对案例） 家长该怎么参与 管得越细越糟：给「松弛感」+ 专业资源，把根搞好而不是托举
第⑦讲 信奥题目难度的真实性 怎么判断「这题到底难不难」 别信颜色：真实难度 = 这道题用的知识点属于哪个组别

闭环关系：④ 给出总量标尺（刷多少） → ② 解决「分从哪来」（怎么拿分） → ① 解决「练完怎么自检」 → ③ 解决「效率怎么提」；⑤ 是外挂情报层——题型池正在变大，把「没见过的题型」提前纳入准备清单；⑥ 是底层建筑——决定前面五件事能不能真正落地；⑦ 是标尺校准——刷题量（④）和颜色评级（①③④）都要先用「真实思维难度」重新校准。

二、第②讲：打暴力分训练法

核心命题：从 0 分到 100 分跨度太大、不现实；应分解为 0 → 有分 → 高分 → 满分。

为什么暴力分重要 - 一等线含金量下降的根因是试题分档设计科学（5/20/40/60/80 分档），让中等生能和顶尖生拉开可得分差 - 数据佐证：2025 J 组第四题（黄题）不会 DP 也能拿 40 分暴力 + 60 分特殊性质 → 很多人 364 分；2024 同组前两题零分、第三题打表 20 + 特殊性质 + 暴力 80 → 260~280 分 - 案例：初一学生 J 组 220 分、始终切不动黄题，转全暴力策略后直接进一等线

落地四步

步骤 具体做法
1. 建真题池 S 组从 2019 年起所有能出暴力分的题 + NOIP 历年真题；黄+绿、绿+蓝难度段基本都能练
2. 改课堂模式 真题排满课上课下；先头脑风暴找检测点（"这 20 分怎么拿"），讨论完立刻现场敲代码；正解放最后讲、投入时间反而少
3. 找不到部分分代码 洛谷提交记录筛「非 AC」状态，直接看 32/40/60/80 分的提交
4. 看不到代码（需先 AC 解锁） 去题解区捞一个满分代码自己交一遍，解锁查看权限
5. 看不懂光秃秃的代码 复制给 AI，附题号 + 要求「暴力分做法解析 + 逐行注释」

理念提炼：不依赖教练/机构资源也能自主落地；"就算学了正解，你也做不出另一道黑题"——难题的作用是练暴力，不是学正解。

三、第①讲：OI 赛制下的自测检查（造数据）

问题本质：OI 没有即时反馈。编译错误（可自行解决）、RE、TLE、WA 全部不可见 → "样例过了是骗人的"，样例只帮你理解题意。

造数据的五个层次

层次 做法 常见误区
① 过样例 必要不充分条件 以为过了样例就稳了
② 读数据规模 按 20%/70%/100% 分档反推 n 的范围 忽略分档信息
③ 极限值 最大、最小、负数、零 样例全正数就不带负数
④ 特殊值 奇偶、边界、零 只测常规值
⑤ 改数据模型 把数字看作排列/图形，改变结构模式 把 5 改成 55 —— 等于没改

核心手法（以"每个数找前面最近的比它大的数"为例） - 把 5 4 3 9 / 1000 999 995 1000 抽象成 ABCD 排列 - 把模式从「一大两小」改成「一大一小」「FEDCBA」（从大到小），才真正覆盖代码分支 - 关键在于改变数据模式，而不是改变数值大小

案例：公交换乘 - 时间 × 票价的四种组合，题目只给了其中三种 → 主动补齐第四种 - 多张地铁票同时满足，用哪一张？题目未明说 → 造 3 张地铁 + 1 张公交验证 - 时间顺序是否线性给出？题目没说 → 造乱序数据

总原则："题目中只要没写的，就都可能"——没说正整数就可能有负数，没说按顺序就可能乱序。改 OI 为 ACM/IOI 赛制，"分数至少能提升五十分"，因为知道错在哪就能改对。

四、第③讲：AI 辅助代码优化

认知前提：代码优化被选手、家长、教练普遍忽视——不是难，是"压根不知道要做"。

信奥 = 数学 + 语文 - 数学面：逻辑/推理/运算，答案唯一 - 语文面：同一思路，不同语法/结构/细节 → 表达不同（"能用一句话讲清楚，就别用三句话"）

AI 用法（关键边界）

该做 不该做
思路不变，只压缩代码结构与细节（学生 40 行 → 优化到 10~12 行） 让 AI 换思路——思路变了导致的简洁是另一回事
  • 有效性来源：过去"突破自己的思维局限"只能求教练/家长改代码，效率极低；AI 让这件事可自助高频完成
  • 对 AI 无门槛要求："国内国外、付费不付费都可以"

收益链条 代码短 → 出错概率低 → 找错改错快（30 行 vs 10 行找同一个 <= 笔误） → 考场时间省出来 → 潜移默化简化思维 → "变成人形 AI 大脑"

案例：学生第一年零基础 J 组 300+（全省第四）→ 习惯代码优化后第二年 J 组满分、半小时做完。

层次洞察：J/CSP 阶段感受不到优化价值（会的就会），到 S/NOIP/NOI "时间永远不够"，比拼的是有效时间内拿到有效分数。

五、第④讲：CSP/NOIP 一等高分需要的刷题量

前提（重要）：刷题量是必要条件而非充分条件——"如果说你其他地方做到位了，那么刷题量到底怎么办；如果你没做到位，实际上你的这个数量就没有意义了"。

⚠️ 颜色体系变动：洛谷 2026 年 7 月起调整了题目难度颜色（新增青题）。该期 PPT 制作于调整前，片中"难题"现在对应青题，对标时注意。

5.1 J 组：一等奖 / 高分

得分结构要求：橙题稳切不失误 → 黄题满分或高分 → 碰到绿题也要有一些暴力分数打底。

阶段 题量 说明
红题 30–50 道封顶 初步接触编程-信奥的入门量，超了就是浪费时间
橙题 150–180 道（普娃求稳 → 220 道） 220 道仍不行就不要再加了
J 组知识点的黄题 150–180 道 别把 S 组的黄题算进来
J 组知识点的绿题 10–20 道 只为一等奖：专门用来训练暴力拿分
同上（冲满分） 80–90 道 要 J 组满分稳当才需要；2025 年 J 组是特例
总量 340–540 道 最低成本拿 J1 ≈ 240 道左右

关键概念——临界点：橙题做到 180 不够可以加到 220，220 还不行就不再加。"很多题它是有临界点的……到达某个临界点之后再努力，实际上是无用功。"

5.2 S 组 / NOIP：一等奖与名次

得分结构要求：黄题满分 → 绿题 70–100 分 → 蓝题 20–40 分 → 紫题/黑题 5–20 分。 （前提是 J 组刷题量已到位——"S 组不存在红/橙"）

阶段 题量 说明
S 组/NOIP 知识点黄题 100 道 各知识点的模板题 + 基础变形，人人可以也应当做到
绿题 130 道 量并不大，仍是知识点的入门与基础应用
蓝题 至少 300 道 主旋律。不足 300 道很难保证赛场稳切蓝题；只刷黄/绿在考场上毫无意义
蓝/紫/黑暴力训练 30–60 道 只为一等奖时，重心应放这里而非蓝题

冲名次 vs 只拿奖（核心分叉） - 切不出蓝题 → 一等奖没问题，但名次不高 - 想进省内前 100 / 前 50 → 难题必须能切，蓝题量必须够 - 只为一等奖 → 重心不放蓝题（难题不需切满分，拿 20–60 分暴力即可），转做蓝/紫/黑暴力训练，30–60 道就够

5.3 总题量标尺（信奥入门 → NOIP）

目标 总题量
稳定一等 / 有名次 1200–1340 道
偶尔一等（靠暴力、含运气与发挥成分） 600–800 道

分项参考：J 红 30–50 / J 橙 150–220 / J 黄 150–180 / J 绿 80–90 / J 蓝 50 / S 黄 100 / S 绿 130 / S 蓝 300 / S 紫 200 / S 黑 10–20。

关于 NOIP 与 S 组：作者认为两者知识点完全一致，只是 NOIP 题目出得更难。所谓"分开"多是机构为了分班（提高班 / NOIP 班）。近几年的省选与 NOIP 都很喜欢出 J 组知识点的难题——所以 J 组基础抛不掉。

5.4 无效刷题：比数量更重要的三件事

  1. 必须总结——每个学生都要有自己的做题总结表：这题学到了什么？错了的话是怎么错的？
  2. 必须融会贯通——做完一批题（比如橙题 5 道 + 绿题 5 道）后，不能逐题孤立理解，而要找出这个知识点在题目中运用的本质。"十道题题面不一样、问的东西不一样，但运用这个知识点的本质是一样的。"
  3. 必须针对性——清楚自己当前的弱项和急需攻克的地方，而不是盲目刷。

金句："我觉得大家在信奥上并不缺乏热爱和努力，你们缺乏的是明确的方向跟内容。你只有先把这个东西定下来，你才能去努力，而不是很盲目地去努力。"

六、第⑤讲：从 26 省选看新题型（趋势情报）

背景：2026 年省选首次出现交互题，6 道题里出了 2 道。这打破了国内信奥「从 J 一路到 NOI 都不出交互/构造题」的常态。

整体题目风格（洛谷评级，后续仍可能调整）

档位 评级
前三道 紫 黑 黑
后三道 蓝 黑 黑
  • 「6 题里 4 黑」从 2025 年省选起已经是明牌；剩下两题是双蓝 / 1 蓝 1 紫 / 双紫，全看出题人心情和考生评价
  • 不变的主旋律：DP 仍是最难的考点，再带点数学、自动机、树链剖分等 NOI 级高阶考点

为什么"迟早要出" - 交互题、构造题在 IOI 里是常见题型，国际上并不偏门——只是国内（J / S / NOIP / 省选 / NOI）一直不出 - 逻辑链：IOI 要出 → 确定金牌（集训队）后，集训队选拔国家队会出这类题，因为要接轨 - 对集训队选手而言「学一个新题型是很快的事」——所以过去一直没往下传导 - 触发信号：2025 年的 J/S 初赛里出现了"由交互题改编的初赛大题"，作者据此预感省选要出

交互题 vs 构造题：门槛完全不同

题型 门槛 建议
构造题 高——有时需要 2-SAT 这类 NOI 级内容 不赘述，"绝大多数人学不到也不会"
交互题 低——入门容易，"你啥都不会也能入门" 优先学这个：掌握提交格式 + 找题练手

核心机制：先输出，再输入（与普通题相反） - 普通题：cin 读入 → 处理 → cout 输出，中间没有交流 - 交互题：先 cout（喂给交互库）→ 再 cin（读回反馈）→ 根据反馈决定下一步 - 关键理解点：「你的输出，实际上就是对方的输入」；交互库内部处理后把结果读回给你 - 例子：洛谷的猜数字——交互库每次返回「大了 / 小了 / 相等」，本质上二分即可

风险与预测

对象 预测
26 年 J + S 99% 不出现
NOIP 20% 概率来 1 道（还要看本次省选的反馈）
  • 真正的风险不是"不会做"，而是不会格式就是 0 分——"可能题目本身会做，但因为不懂得怎么交互，得不到任何分"
  • ⚠️ "绝大部分老师不会教，而且老师本身也不会"——必须自己单独学
  • 作者现场演示：洛谷题库筛选交互题有 400+ 道（其中混有构造题），题目自带标准答案，可自己拉下来试

七、第⑥讲：家长对学生的影响（根本中的根本）

作者的定位："比起某个知识点或者某道题怎么做，我觉得这个是根本中的根本。因为这个决定了你的底层建筑。" 讲的是学生与家长绑定的案例——学生性格 + 家长性格 + 家长对待孩子的方式 → 最终走向不同。作者自述样本上千。

7.1 案例一：同校同班两个男生 A / B（妈妈的区别）

A B
起点 同样聪明、同时入选校队、从零学 C++ 同左
校队水平 校内第一、第二 同左
考前冲刺 来了 没来
第一年 CSP 二等奖 J 组第 42 名
妈妈的姿态 经常跟老师聊，聊的是孩子在生活里的事（跟妈妈吵架、跟同学闹矛盾），从不问"今天做了什么题、拿了多少分" 见面时"好像是一种比较骄傲的状态"
第二年 每天放学回家自己刷题（刷到班主任都喊家长）→ CF 比赛全省第九 态度越来越散漫，到"作业都不做" → CSP 复赛连 100 分都没有

老师第一次见 A 妈妈，是在 A 考砸之后放学后拉到教室门口聊了 20 多分钟，核心三句话： 1. "那个同学确实比你要聪明，所以这次考试比你考得好" 2. "但我觉得很大原因是这次题目偏思维，跟信奥知识点关系不大，你们俩分数在我看来都很正常" 3. "你要咽不下这口气，那就努力一点——我觉得这个东西比什么都有用"

并当场做了预言："你别看他好像聪明一点，但我觉得他不太认真。这个聪明在初期可能让你觉得有差距，但学习时间拉长之后，你会发现你会赶上来的。"（后来应验）

7.2 两类"帮不上忙"的家长

① 「尴尬的家长」——看似忙得热火朝天，实则没有任何帮助

幻灯片原文列举： - 整天盯着"孩子今天刷了几道题"，热心做数据表、拉数据，"特别漂亮" - 今天几道橙题、明天几道黄题、做了多少分 - 整天在各个群里逛，聊"谁家孩子又厉害了" - 今天让孩子打这个比赛、明天做那个；各种小比赛、小测验、考级 - 看到分数当个很重要的事，"就在那开始当军师分析起来了" - 自己稍微懂点信奥知识点的名字（比如 DP、线段树），就问孩子"DP 搞懂了吗"

老师判断："这一类最后成绩都不咋地"——"你仿佛好像很操心很忙，但其实你没有忙到点子上去，然后你自己就显得很累。学生一看爸爸妈妈参与的这么多，他压力也很大。"

作者自述："我从来没有加过任何一个信奥群……绝大多数信奥群里并没有任何干货或有营养的东西，只是一堆家长的自嗨。"

② 管得很细 / 很严 → 高概率出「超纲」问题

"凡是管得很细或者管得很严的，在信奥里会有极高概率发生超纲的问题，其实就是作弊的问题，一定会有。"

7.3 真正帮上的两类家长（两个女生，都是爸爸在管）

老师观察："我见到的 95%，男生都是妈妈管，女生都是爸爸管。"

A 的爸爸——大学计算机专业老师 - 论专业出身比绝大多数家长内行，完全可以自己教、事无巨细地过问，但他从来都没这样做 - 也不跟老师聊这些，两人聊的是"国外哪个地方好、吃的怎么样、天气怎么样" - 第一次孩子去"尝试" CSP 初赛，他自己先把初赛真题做了一遍、学了一遍 - 还把每道题的 ABCD 为什么对、为什么错写成公益公众号文章——"相当于给自己女儿做学习资料"，同时做公益；"那个东西是我见过全国做初赛做得最好的，没有之一" - 孩子零基础跟老师学半年多，八级过掉，后来比赛都很好

老师最看重的不是成绩，是「松弛感」

"这个家长给我最大的感受是有一种松弛感……相反他们会让我觉得很紧。在我这里有松弛感的家长，最后考得都很好，这是绝对的。"

"他能管，但他不管得那么细致；他很多时候都是用自己的专业水平找资料，让孩子自己学。他不会说'来，爸爸今天教着你学'，但真到要出手的时候，别人是真的干事情。"

金句："卷孩子不如卷自己。"

学生的关键优点：「听话」= 听劝 - "百分之九十九的孩子是不听话的，因为他改不掉那个固有的习惯问题" - "你跟他说一次就很棒"——老师让改代码风格（为 26 年做紫题准备），他听到立刻就改，再做模拟卷就很快 - 反例：很多信奥生很固执，"这个固执的性格，把他们害得很惨"

B 的爸爸——自己教语法，然后陪学 - 本身打竞赛出身，明白"竞赛不能吃大锅饭，一定要找单独老师" - 他一开始也只懂一点编程（不懂信奥），于是每节课陪着女儿一起上、一起学、一起做题、代码错了一起改 - 出差到美国都捧着书在学——"真正的参与其中，而不是只是每天在那看个热闹" - 结果：能感同身受女儿的想法、困难与毛病，父女关系"还算融洽"

7.4 案例三：两个刚上初一、自己上网找老师的学生

共同点：不是家长带着学，是自己很想学——主观能动性。

男生 A - 本来有校队、也在线下机构学；六年级毕业那年，本地区赛没过、J 组初赛也没过 - 家长觉得"是不是已经不适合学这个东西了"；但学生本人觉得自己没问题，是老师没教明白 - 于是自己上 B站翻遍所有讲信奥的（当时还不多），反复私信聊了半个多月，自己先跟老师把事情谈好，才跟妈妈讲 - 他妈妈当时还问"学了信奥吗"，老师回"很适合学信奥"；妈妈"还以为从此没信奥这回事了" - 结果：跟学一年 → J 组初赛从没过到满分，J/S 复赛双一等；第二年 → 本地区赛第 1、市赛第 9；25 年 J 组满分 - 妈妈的态度：第一年初期还问过一两次"孩子学得还好吗"，任何信奥专业问题都不问（"甚至橙题黄题是什么都不太了解"）；第二年以后基本不问，"完全放心" - 老师点评："什么事情都是我跟孩子交代，不需要家长作为中间人去传话……学生才是真正的执行人，你总是靠家长传话，这个本身就不好"

女生 B（页面上直接贴了她写给老师的原话）

"偶然在视频平台上看到了您的讲解——每一处知识点都讲得清晰透彻，细节更是拉满，瞬间帮我打通了思路……"

"参加 NOI 一直是我心心念念的目标。可长久以来，一个难题一直困扰着我：哪怕是曾经熬了一个晚上攻克的难题，过段时间再回头看，还是会变得生疏，甚至完全想不起解题思路。直到您的视频我才恍然大悟，原来要整理做题笔记才是关键！我立刻试了一段时间，对比您给的表格，发现自己的记录实在太零散，差了一整个档次。"

"通过之前的学习，我彻底摸清了自己的底细：能看懂、能模仿、独立完成，完全是三个不同的层次！现在的我勉强能看懂，模仿还得费不少劲，独立完成基本无从下手。我想，应该还是基础不够扎实，学过的题就像死记硬背的公式，根本没法灵活套到不同的题目里。"

老师点评：

"我只要遇到这样的学生，我很清楚：只要能有时间刷题，外加天赋足够支撑起码的成绩，最后成绩一定都不差的。因为你不用跟她去废话什么学习态度、方法，别人自己就会调整。"

（老师与她的约定："我要跟她自己聊，不用通过家长传话。"）

7.5 结论：把「根」搞好，而不是一味托举

  • "凡是我发现那些有实力、真正做事情的人，他们往往伴随着一个不太管的家长"
  • "我建议家长一定要多让孩子自己做事情"
  • 事无巨细的家长"做了很多本来学生可以做的事情"，还"有形无形地给孩子增加了很多额外的任务"
  • 不是孩子做不了，是你没给他机会尝试："只要稍微尝试一下做错了……你一错你就批评他，他就更不想做"
  • "你不如想一想怎么样把这个根搞好，而不是说你一开始是错的，然后总想着去托举。真正厉害的都是自己托起来的。"
  • "现在很多家长是小学拖、初中拖，发现渐渐拖不了了，半拖高中彻底拖不了……现在很多家长在信奥这个事情上很尴尬，就是他上不去，但是也下不来。"

八、第⑦讲：题目难度的真实性（别被颜色骗了）

核心命题：洛谷的颜色划分不等于思维难度。真正的难度取决于这道题用的是哪个组别的知识点——而组别的划分本身是人为定义的。

8.1 作者的「真实难度换算」

J 黄 = S 绿 = NOI 蓝（以此类推，每过一个组别往上抬一档）

  • 同样标成「绿题」的两道题，内在思维难度可能差别极大——取决于知识点是高阶还是低阶
  • 用「J 组知识点」解决的黄题，思维难度 ≈ 用「S 组知识点」解决的绿题
  • "我不是说 S 组考试里面那个题，我说的是你那个颜色的题，用的是哪个组别的知识点。"

8.2 为什么「高阶」不等于「难」（微积分 vs 四星的比喻）

题目 用到什么 作者打的"星级" 实际思维难度
A 套一个微积分公式就能解 七星级 其实没有思维难度——"你只要学了公式就 OK"
B 不用微积分，就是很普通的运算 四星级 思维难度很高

"这个多少星是我瞎编的。" —— 星级的定义权在评级者手里，跟思维难度不是一回事。

落到行动：日常刷题不能只看颜色，要看"你用的这个知识点是什么"。

8.3 现场演示：同一个知识点，评级差两个身位

作者当场翻洛谷题单作证：

屏幕上的题单 评级 说明
最小生成树 / 并查集 / 单源最短路径 / 堆 / 最近公共祖先 LCA / 负环 / 传递闭包 / 拓扑排序 / Floyd 全 黄 全是 S 组最基础的知识点模板
可持久化线段树 / 2-SAT / AC 自动机 / 扩展 KMP / Dirichlet 前缀和 / exgcd / 二分图 · 线段树分治 / 带修莫队 / 点分治 / Lucas 定理 / 自适应辛普森 提高+/省选− 全是 NOI 组别知识点——"一点都不难"

关键推论： - 考场上的题一定高于该知识点模板题「高一个或高两个」档，绝不会跟你练的模板一模一样 - 例：22 年 ST 表是绿题；去年 NOIP 最后一题考了 LCA；并查集 NOIP 近几年也考过——"他们的难度全是在模板之上的" - 所以日常刷题要留出自己的深度，而深度靠模板题的难度来掌控

8.4 一个常见幻觉：第二年「进步」了

  • 第一年做 J 组黄题，第二年做 S 组绿题，自我感觉进步了——其实难度完全一样，是原地踏步
  • 更典型的失败模式：翻某个竞赛生的历史记录，做了不少紫题、黑题，可到了考场上做蓝题一样不行
  • 原因：他刷的全是 NOI 组别的知识点，不是 S 组的知识点

8.5 收尾：宁可做 NOI 紫题，也不愿做 J 组蓝题

"不要沉溺于题目难度的颜色，而忽略思维难度的真实性。我自己上 NOI 的课，一道紫题 5 分钟就讲完了——因为模板随便改一改就完事。我见过的学生也是：宁愿做 NOI 的紫题，也不愿做 J 组的蓝题，因为后者更难。"

九、七讲的共同底层逻辑

  1. 分数导向，而非知识导向：以"能拿到多少分"而非"学会了多少算法"组织训练
  2. 把 AI 当基础设施：AI 解析部分分代码（第①讲）+ AI 优化代码（第③讲），都是自助可完成
  3. 可自助落地：各讲都反复强调"不依赖机构/校队资源，在家也能做"
  4. 真题驱动：所有练习都锚定历年真题，不做泛题
  5. 够用即止 / 临界点意识：刷题量、暴力训练量都有明确上限（橙题 220 为止、暴力 30–60 道），过线后的投入是"无用功"
  6. 以「真实难度」而非标签导航：颜色、星级、题量都是外在标签；判据是「这道题用的是哪个组别的知识点、逼你动了多少脑子」
